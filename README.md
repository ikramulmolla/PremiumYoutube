# YouTube Premium (NouTube Mod)

A modified build of the NouTube open-source client providing enhanced playback
experience similar to YouTube Premium.

### ✨ Features
- Watch YouTube videos **without ads**
- **Background playback** supported
- **YouTube Music support included**
- Works smoothly with additional optimizations
- Fully rebranded UI (name, icon, splash)
